Spielregeln

  1. Ziel: Eine einzige deiner fünf Figuren mit genauem Wurf auf das goldene Zielfeld oben bringen.
  2. Würfeln: Einmal pro Zug, dann eine Figur exakt so viele Felder ziehen. Keine Sonderregel bei einer 6.
  3. Start: Die fünf Figuren jeder Farbe benutzen gemeinsam das schwarze Einstiegsfeld mittig über ihrer Fünfergruppe. Das ist immer Feld 1, unabhängig davon, auf welchem der fünf farbigen Startplätze die Figur steht. Eine bestimmte Würfelzahl ist nicht erforderlich.
  4. Wege: Vorwärts, seitwärts, rückwärts und an Kreuzungen abbiegen ist erlaubt. Du darfst innerhalb eines Zuges kein Feld doppelt betreten. Figuren lassen sich überspringen.
  5. Schlagen: Landest du auf einer gegnerischen Figur, muss sie zu ihrem Startplatz zurück. Auf einem Feld steht nur eine Figur.
  6. Sperrsteine: Du darfst sie nicht überspringen. Landest du mit exaktem Wurf auf einem, versetze ihn auf ein freies Feld – ausser in die unterste Spielfeldreihe.
  7. Aussetzen: Ist bei deiner Augenzahl kein Zug möglich, geht der Zug automatisch weiter.
