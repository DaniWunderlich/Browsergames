# KABELSALAT TV 1991 — Die große Fernsehsatire 📺🎬

## Das Spiel

Metaspiel über Fernsehen. Moderiere eine Sendung, verstricke dich in Kabelsalat (buchstäblich), reagiere auf chaotische Ereignisse. VERY meta. Very 90s.

## Wie man spielt

- **Ziel:** Sendung am Laufen halten trotz ständiger Probleme (oder absichtlich sabotieren)
- **Steuerung:** Click-to-interact, zeitbasierte Entscheidungen
- **Chaos:** Ist das Feature oder Bug? Ja.

## Features

✅ Meta-Humor  
✅ TV-Satire  
✅ Chaotische Ereignisse  
✅ 90er-Ästhetik  
⚠️ "Spiellogik" ist größtenteils Zufall
