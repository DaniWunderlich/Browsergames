## 🚀 How to play

1. Choose a game under `games/` and download its `.html` file. On GitHub, open the file and select **Download raw file**. Alternatively, download the entire repository via **Code → Download ZIP** and extract it.
2. Open the downloaded `.html` file in your browser.
3. Play, crash, try again.
4. Found a bug? Embrace it or [open an issue](https://github.com/DaniWunderlich/Browsergames/issues) — either works.

## 🛠️ Technology & tests

Each game is a self-contained **HTML file with embedded CSS and JavaScript**. You do not need a build step, package manager or server to play.

Automated tests and GitHub Actions workflows are not currently set up, so there is no test or CI status badge yet.
