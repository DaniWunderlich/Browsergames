## 🚀 Wie man spielen kann

1. Einfach ein `.html`-File aus diesem Repo herunterladen
2. Im Browser öffnen
3. Spielen, crashen, nochmal versuchen
4. Bei Bugs: Umarmen oder Issue schreiben (beides geht)
